# Workflow review

| Workflow | Tool | Boundary |
| --- | --- | --- |
| URL expires during transfer | Rescue download | Validator/sample checks; final publisher checksum still matters |
| Complete record, moved disk file | Library health | Checks recorded locations, not all disks |
| Repetitive names/destinations | Favorites, rules, batch rename | Task rename does not rename completed disk files |
| Panel blocks the page | Drag, minimize, close, site hide/reset | Browser page restrictions still apply |
| Downloads interrupt browsing | Traffic profiles and HTTP queue caps | Limits vary by transport |
| Accidental task removal | Recovery bin | Physically deleted completed files cannot be restored |
| Move chosen configuration | Selective backup | Not a file, partial-data or key backup |
| Audio or shorter clip needed | Media workshop | Completed local media, one job at a time |

See [feature guide](FEATURES.md) for capacities and [validation](VALIDATION.md) for evidence. No bug-free or universal-site claim is made.
