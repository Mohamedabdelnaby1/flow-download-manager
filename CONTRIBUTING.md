# Contributing

Start with a reproducible issue or focused proposal. Include Flow/Windows/browser versions, installer or portable edition, exact steps and expected behavior. Redact cookies, tokens, authorization, private URLs and personal paths.

Use Node 22, `npm ci`, `npm run native` and `npm test`. Inspect UI changes with the full stylesheet order, English LTR/Arabic RTL, all appearance modes, compact windows and 150% scaling. Check real bytes and failures for transfer changes.

Keep changes focused; omit generated binaries, databases and profiles. Explain tests actually run and remaining gaps. Preserve creator attribution and third-party notices.
