# Security

Never publish credentials, cookies, pairing tokens, private download URLs, databases or key files in issues. Use redacted diagnostics for ordinary reports.

For security-sensitive issues, contact the maintainer privately through the [creator profile](https://www.facebook.com/mohamedabdelnaby190). Avoid posting sensitive data or exploit details before investigation. No response-time guarantee is offered.

The current release is the intended maintenance target. Release hashes verify integrity against metadata; unsigned binaries do not offer publisher-certificate assurance. Keep bundled utilities and their source/license notices together.
